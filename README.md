# AMR AI Chat Application

واجهة شات تفاعلية تعتمد على Cloudflare Workers واستجابات الذكاء الاصطناعي المجانية.

## الميزات
- دعم نماذج متعدّدة: GPT-4o Mini, Claude 3 Haiku, Llama 3.3 70B, Mixtral 8x7B.
- تصميم عصري وسريع متوافق مع كافة الشاشات والأجهزة.
- ربط مباشر عبر API سحابي مستضاف على Cloudflare Worker.
